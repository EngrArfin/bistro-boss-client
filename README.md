# React + Vite

SA Food Restaurant is a comprehensive client-side web application designed for a modern restaurant, offering a seamless experience for customers to explore the menu, place orders, and make payments online. The application is built using a robust stack of technologies, including HTML, CSS, Tailwind CSS, DaisyUI for a visually appealing and responsive design, and React for dynamic user interactions. The backend is powered by Express.js and MongoDB for efficient data management, while Firebase handles authentication and user management. Secure transactions are ensured through JWT for authorization and Stripe.js for payment processing. The application also leverages Axios.js for smooth API requests, making the ordering process fast and reliable.

## Tech Stack

**Client:** HTML, CSS, Tailwind CSS, DaisyUI, React,
 Express.js,MOngodB,Firebase,axios js, JWT,payment stipe.js
